## 🌌 Overview

**AI Incubator** is a personal AI development environment where I design, test, and build **AI-powered educational tools, assistants, and experimental prototypes**.

This repository is not just a project — it is a **long-term AI engineering journey**, where each module represents a step toward building intelligent, human-centered learning systems.

---

## 🎯 Vision

The goal of this incubator is to explore:

- 🤖 How AI can teach humans (AI-as-a-tutor systems)
- 🧠 How large language models can be structured into learning paths
- 📚 How education can be personalized using AI
- ⚙️ How simple prototypes evolve into scalable AI applications

## 🧩 Core Projects Inside This Repo

### 📘 1. AI Tutor (Week 1 Prototype)

> A Streamlit-based interactive AI tutor that teaches foundational AI concepts in a structured learning format.

#### ✨ Features:
- 💬 Conversational AI learning interface
- 🧭 Structured "Week 1" learning system
- 🧠 Step-by-step concept explanations
- 🎓 Beginner-friendly AI education flow
- 🔁 Interactive Q&A with instant feedback
- ⚡ Lightweight Streamlit UI

#### 🎯 Purpose:
To simulate a **personal AI teacher** that doesn’t just answer questions, but guides understanding.

## 🚀 How to Run Locally

### 1️⃣ Clone the repository
```bash
git clone https://github.com/Asteria267/AI_incubator.git
cd AI_incubator
````

---

### 2️⃣ Install dependencies

```bash
pip install -r requirements.txt
```

---

### 3️⃣ Launch AI Tutor

```bash
streamlit run ai_tutor/app.py
```
