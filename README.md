# 🤖 AI Tutor – Streamlit Learning Assistant (Week 1)

An interactive AI-powered tutor built with **Streamlit** that teaches foundational AI concepts in a simple, structured, and beginner-friendly way. This project is part of a learning journey where I’m building an AI tutor step-by-step.

---

## 🚀 What it does

This AI Tutor helps users:
- Understand basic AI concepts in a structured way
- Ask questions and receive explanations in real-time
- Learn step-by-step like a guided course (Week-based learning system)
- Practice thinking through AI concepts interactively

Instead of just giving answers, the tutor focuses on **learning and explanation**, making AI easier to understand for beginners.

---

## 🧠 Key Features

- 💬 Chat-based AI learning interface
- 📚 Structured “Week 1” learning module
- 🧩 Concept breakdown into simple explanations
- 🔁 Interactive Q&A with the tutor
- 🎯 Beginner-friendly AI education approach
- ⚡ Fast and lightweight Streamlit UI

---

## 🛠️ Tech Stack

- Python 🐍
- Streamlit 🎈
- OpenAI API / LLM (if used)

- Basic frontend via Streamlit components
